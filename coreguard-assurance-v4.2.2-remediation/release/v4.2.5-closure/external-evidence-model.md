# External Evidence Model — Decision B (Option B)
**Gate 4.1 · v4.2.5-closure · 2026-09-18 · Directive P1: حسم نموذج الأدلة الخارجية**

## القرار المعتمد
الخيار **B — اعتماد صريح على أدلة خارجية**: الدليل الإلزامي للـ Standard Run
(`kit` + السجل المرجعي للحزمة المجمّدة) هو **أصلٌ إجرائي حقيقي خارج المستودع
بالتصميم**، لأنه جوهر ما تجري مراجعته المستقلة — تضمينه داخل المستودع سيجعل
المراجع يعيد التحقق من أدلة المؤلف بنفسه (تضارب مصالح بنيوي، لا مجرد تفضيل
هندسي).

## السلوك المعتمد عند غيابه (fail-closed، مقصود ومُختبر)
```
Standard Run على استنساخ نظيف بلا reviews-extra/ →
  INV-001 (kit exists)  = BLOCKER / fail-closed → BLOCKED
  EXT-001 (drift map)   = MAJOR   / fail-closed → FAIL (entries MISSING)
  POL-002 (coverage)    = INCONCLUSIVE (failClosed:true)
  exit code = 1 — الحكم الصادر: BLOCKED، وليس PASS أبدًا
```
هذا السلوك **مُختبَر وموثق**: استنساخ نظيف من GitHub أُنشئ تحديدًا لأجل هذا
الإثبات (دورة v4.2.4، commit `83ac866`)، وأظهر `exit 1` مع BLOCKED/FAIL
كما صُمم. يُمنع منهجيًا تسجيل نتيجة PASS لاستنساخ بلا أدلة إلزامية — النتيجة
الوحيدة المقبولة حينها هي **BLOCKED مع ذكر الدليل الغائب بالاسم**.

## بروتوكول إدخال الأدلة للمراجع المستقل (C8)
1. استنساخ `main` على `EslaM-X/coreguard`.
2. الحصول على `reviews-extra/` من المالك (قناة خارج المستودع).
3. مطابقة هاش كل دليل مقابل القيم داخل `verification-drift-map.json` — أي
   اختلاف يوقف المراجعة.
4. عندها فقط يُشغَّل Standard Run ويُقبل حكم PASS/BLOCKED الموثق.
