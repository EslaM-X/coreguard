# CoreGuard — ورقة واحدة للمستثمرين / الحضانات (2026-09)

**CoreGuard طبقة تحقّق حتمية (deterministic) تفشل إغلاقًا (fail-closed) بين
أدلة تنفيذ الوكيل والتحكيم** — الجزء الناقص في كل منصّات مدفوعات الوكيل.
MIT مفتوح المصدر. كل ما يلي قابل لإعادة الإنتاج من الشجرة المثبَّتة بأمر واحد.

التواصل: افتح issue أو PR على المستودع.
الرابط الخارجي الوحيد المستخدم:
https://github.com/EsLaM-X/coreguard/releases/tag/v0.6.0

## 1. المشكلة

- وكلاء الذكاء الاصطناعي ينفّذون معاملات؛ الإيصال يُثبت *التنفيذ*، لكن لا شيء
  يُثبت حالة الموافقة المحيطة أو الحدّ قبل التسوية.
- أنظمة فضّ النزاعات تريد أدلة قابلة للتحقّق آليًا؛ اليوم عبور الأدلة إلى
  المحكمة منطقة مظلمة من سجلات غير قابلة للتحقّق.
- فرق الأمان تطلب الفشل الإغلاقي: أي تغيير بحرفٍ واحد يجب أن يُرفض، لا أن
  يُعاد تغليفها — لكن معظم خطوط الأدلة يعيد التغليف بصمت.

## 2. المنتج والإثبات (كله حقيقي، كله داخل المستودع)

```
execution evidence → consent state → ADAL/1 dispute package → tribunal adapter → external award → authorized settlement
```

- **حتمي + فشل إغلاقي:** فحوص SHA-256؛ أي تغيير بحرفٍ واحد يُرفض، والديمو
  *يخرج برمز خطأ إذا لم يحدث الرفض*.
- **موافقة ثلاثية صادقة:** `FULL / PARTIAL / UNKNOWN`؛ الأدلة الناقصة لا
  تتحوّل أبدًا إلى موافقة ثنائية.
- **991 اختبارًا ناجحًا** (conformance + delivery) مع CI أخضر — والانضباط
  الأخلاقي مُختبر أيضًا (المجموعة تتأكد أن المشروع لا يبالغ أبدًا في الادعاء).
- **تجربة L1 `VERIFIED` على Core Mainnet:** تحويل حقيقي، tx
  `0xe67c61fd…6891a9b8`، بلوك `38712625` — إعادة حساب مستقلة مقابل التفويض
  المُعلَن مسبقًا؛ السجل المركزي يحمل بالفعل مراسي إثبات مجمَّدة.
- **أداة جاهزة لحساب اختبار (harness):** تبني وتثبّت حزمة x402
  `adjudication.prepare()` (مع `idempotencyKey` حتمي) وتعيد تشغيل بث webhooks
  مسجَّلًا (إزالة تكرار `eventId` + مؤشر تسلسل) — بأمر واحد ودون اتصال،
  `networkCall: NOT_PERFORMED`.
- **أداة تكيّف بنيوية + محكمة مرجعية:** خريطة دون اتصال نحو أسطح فضّ نزاعات
  خارجية؛ خانة الحكم تبقى `UNKNOWN`؛ escrow يبقى مرجعيًا فقط
  (`deployed:false`).

## 3. السوق ومسار الإيراد

من يدفع: **منصّات الذكاء الاصطناعي/الأتمتة** التي لديها مسؤولية الوكيل؛
**أمناء الحفظ ومشغّلي الخزائن** الذين يريدون إثباتًا بمستوى التدقيق؛
**مدقّقون/أوراكل** يعيدون بيع مُصادقات التنفيذ (CoreGuard كأصل بدائي).

خدمات قابلة للبيع — البروتوكول يبقى MIT مفتوحًا (هذا سطح الثقة):

1. **تشغيلات التحقّق** — تحقّق مدفوع قابل لإعادة الإنتاج لتسليمٍ وفق معايير
   قبول مثبَّتة → سجلّ جاهز لنزاعات ADAL/1. 2000–10000 دولار لكل تعاقد (نطاق،
   ليس عرضًا)؛ مكتمل ≈95%.
2. **صيانة أداة التكيّف** — اشتراك شهري لإبقاء خريطة سطح خارجي محدّثة (تحديثات
   مخططات، مستقبِل webhooks، فحوص نزاهة الحزم).
3. **أدوات المحكمة المرجعية** — ترخيص محاكي الفشل الإغلاقي كمرجع مطابقة.
4. **SDK حدود التسوية (v0.2+)** — يرفض تنفيذ تسوية دون حكم مُحقق التوقيع
   والـcredential المقيد بالسلطة؛ التنفيذ محكوم بالحوكمة، ولا يحمل مفاتيح.

سلسلة إشارات 12 شهرًا: أول تعاقد تحقّق مدفوع → أول تشغيل من مُتحقّق خارجي →
أول تسليم حي من طرفٍ ثالث (مدمِج بحامل credential) → أول تكامل خارجي.

## 4. الطلب (مقيد بالمراحل، Core-native)

1. **M1 — إغلاق الخطوات الحية L1–L3.** مُدمِج بحامل credential يسجّل منحة
   سلطة حية مؤكَّدة من المنصة، و`adjudication.prepare()` مقبولة، وإعادة تشغيل
   بث webhooks. التمويل يغطي الهندسة وتعاقد المدمِج.
2. **M2 — واجهة توقيع محكمة عامة** (استيعاب حكم مستقل عن الأداة + عقد تحقّق
   التوقيع).
3. **M3 — SDK حدود التسوية** لطبقات المحافظ/الجدار الناري (مسار تنفيذ وهمي في
   المطابقة؛ التنفيذ الحقيقي يبقى محكومًا بالحوكمة).

## 5. لماذا نحن

- **بنيناه بالفعل** — لا عروض تقديمية: محرّك حتمي مُختبر خصوميًا بأدلة قابلة
  لإعادة الإنتاج وصولًا إلى قراءات السلسلة.
- **صدق المدقّق** — `VERIFIED ≠ SAFE` في بند README الأساسي؛ لن نبيع «يمنع
  كل الاستغلالات».
- **منضبط النطاق** — لا مسرح لوحات، لا مقاييس مزيفة، لا ادعاءات أمنية غير
  قابلة للتفنيد؛ كل حالة قابلة لإعادة الإنتاج من `npm test`.

## 6. ما لن ندّعيه

- لا يوجد تكامل حي مع People's Court أو غيرها — الأسطح **DRY-RUN** حتى وجود
  تأكيد مسجَّل (L1–L3)، ولا يُحفظ أي credential لأي طرف داخل المستودع.
- لا سلطة تسوية، لا سلطة بث على الشبكة الرئيسية، لا escrow — `CONDITIONAL
  NO-GO` ملزمة، و`deployed:false`.
- لا «ضمانات أمنية»، ولا اعتماد/شراكة/تمويل مزيف، ولا مقاييس مزيّفة.
