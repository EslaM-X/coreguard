## 1. The value pipeline

```
Protocol / Agent  →  CoreGuard verification  →  auditability + trust
      ↓                       ↓                        ↓
  execution flow   deterministic receipt      enterprise / protocol
  on Core Mainnet  (VERIFIED|INVALID|          integration
                   NOT_PROVEN|NOT_RUN)              ↓
                                                Revenue
```

Two-sided logic:

- **Cost side:** verification, not liquidity. No TVL to attract, no capital
  burden — the "product" is per-execution determinism.
- **Demand side:** buyers pay for *risk reduction* (auditability, attribution,
  fail-closed evidence), which institutional budgets already fund (audit,
  compliance, agent-ops) — not for speculation.
