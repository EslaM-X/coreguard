**"Did this transaction actually do what was authorized?"**

- No independently verifiable evidence of conformance

## Slide 2: The Solution
**CoreGuard = Verifiable Execution Truth Layer**

- Produces cryptographic evidence of conformance
- Independent recompute (no trust required)
- Machine-verified, not human-reviewed
- Works across Core DAO, Stellar, Pi Network

## Slide 3: How It Works
```
Intent → Policy → Execution → Evidence → Replay → Verdict
```
1. Define what should happen (intent + policy)
2. Execute the transaction
3. Generate cryptographic evidence
4. Independently replay and verify
5. Output: VERIFIED / REJECTED / UNKNOWN
