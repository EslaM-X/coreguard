What CI actually measured last: the SDK and wire runner reports, their budgets and trend — fetched from the public API and the committed perf history, no token, no server, no clone. These are recorded measurements, not promises.

مصادر الصفحة، كلها عامة وبلا توكن: api.github.com (آخر تشغيل ناجح لـdde.yml وأدلته) · raw.githubusercontent.com لملف benchmarks/perf-history.jsonl (المقاييس التي يلحقها DDE Evidence Cycle وتلتزم كل دورة) · raw.githubusercontent.com لوحدة scripts/benchmark-trend.mjs (جدول الميزانيات: السلسلة ← الميزانية الوسيطة). الميزانيات والسلاسل مشتقة من ذلك الجدول لحظة العرض — لا رقم ميزانية معاد كتابته هنا، والتقارير الكاملة تُرفع كـartifact باسم dde-runner-reports لكل تشغيل مع احتفاظ 30 يومًا. إن تعذّر مصدر فتظهر الشارة حمراء باسمه: الصفحة لا تعرض صمتًا ولا رقمًا قديمًا باسم حاضر. Sources, all public and token-free: api.github.com (latest successful dde.yml run + its artifacts) · raw.githubusercontent.com for benchmarks/perf-history.jsonl (the medians the DDE Evidence Cycle appends and commits every cycle) · raw.githubusercontent.com for the scripts/benchmark-trend.mjs budget table (series → median budget). Budgets and series are derived from that table at render time — no retyped budget number here; the full reports upload as a dde-runner-reports artifact per run with 30-day retention. A dead feed renders its own red chip: this page never shows silence, nor an old number wearing a live name.
