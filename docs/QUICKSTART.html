أوّل أمر يكتبك في مشروع تكامل خارجي: create:integration يولّد هيكلًا جاهزًا من القالب الرسمي — وضعه الافتراضي يعطيك أرضية الحارس (authorize → verify → anchor) بالوحدات المرجعية، ووضع --dde يعطيك قوالب الأدلة ثنائية الأطراف + محرّك الحدود مستقلًا + بوابة الدفع التي لا تُطلق إلا بمحرّك VERIFIED و قبول موقّع من الطرفين. كل أمثلة هذه الصفحة حية: الأوها مشتقّة لحظة العرض من بايتات السكربت نفسه، وقائمة الملفات من GitHub API، وجدول المحرّك يعمل فعليًا في تبويبك على القالب المرتبط بالمستودع — لا نص منسوخ يدويًا ولا رقم معاد كتابته. The first command that puts you in an external integration project: create:integration scaffolds from the official template — its default mode gives you the guard floor (authorize → verify → anchor) on the reference SDK, and --dde gives you the ten DDE/1 evidence records, the standalone boundary engine, and the payment gate that releases only on engine VERIFIED and signed two-party acceptance. Every example on this page is live: commands derive at render time from the generator's own bytes, the file trees come from the GitHub API, and the engine table actually runs in your tab against the committed fixture — no hand-copied prose, no retyped number.

The committed fixture carries a REJECTED verdict on evaluated criteria — so the gate shows HOLD with its reasons. What a settled transaction changes: nothing.

Public, token-free sources: raw.githubusercontent.com for the generator script, package.json, engine-dde.mjs, payout-gate.mjs, the SHA-256 shim and the ten dde-fixture/ records; the GitHub API contents endpoint for both template trees.
